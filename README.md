Probabilistic Topology Evolution and CH Optimization using CDO in WSNs
Overview

This project proposes an energy-efficient Wireless Sensor Network (WSN) framework that combines:

Probabilistic Topology Evolution (QTBE)
Cognitive Decision Optimization (CDO)
Minimum Spanning Tree (MST) Routing

The objective is to improve network lifetime, energy balancing, scalability, and fault tolerance.

Key Features
Dynamic probabilistic topology formation
Energy-aware Cluster Head selection
MST-based inter-cluster routing
Multi-round energy depletion simulation
Network lifetime analysis
Node death rate evaluation
